# Argand
Independent senior maths tutor prototype. Not affiliated with Mathspace.
React/TypeScript worksheet; Python FastAPI server; restricted mathematical parser and exact SymPy arithmetic. Keep API credentials server-side and load only through Isaac's canonical service loader. Never label authored guidance or fixture judgments as model results. Unsupported mathematics remains not checked. SQLite owns immutable attempt records, voice transcript excerpts and evaluations. Voice transcript snapshots are captured on Evaluate or connection close; do not claim they are complete spoken turns. External model calls follow learner actions: checking typed answers or collecting exact roots with the practice sliders, Ask for help or starting a GPT-Live voice conversation in the learning space, or Evaluate in the inline evidence panel, or completion of the correct root collection (including OpenAI explanations of flagged assertions). Tests exercise known correct, incorrect and unsupported inputs. Run `npm --prefix frontend run build` and `.venv/bin/python -m pytest -c backend/pyproject.toml backend/tests` before committing. Local preview binds to 127.0.0.1.

UX: Keep the interface minimal and clear. Use text for learning content and necessary actions; omit decorative slogans, repeated guidance and explanatory filler.

Structure: frontend code and its build configuration live in `frontend/`; the Python package lives in `backend/argand/`, with unit/API tests in `backend/tests/`. Cross-application browser journeys live in `tests/browser/` and operational helpers in `tools/`. `server.py` owns HTTP orchestration, `math_checks.py` exact maths, `curriculum.py` authored content, `storage.py` immutable records and `evaluation.py` model judgments. Frontend entry is `main.tsx`; application flow lives in `App.tsx`. Real and deliberate-failure summaries share `EvaluationSummary`. Keep shared evidence types in `evidence.ts`. Format TypeScript/CSS with Prettier and Python with Ruff; `npm --prefix frontend run format:check`, `ruff check --config backend/pyproject.toml .`, build and pytest are the baseline checks. Browser evidence paths must be portable, never personal absolute paths.
