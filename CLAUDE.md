# Argand
Independent senior maths tutor prototype. Not affiliated with Mathspace.
React/TypeScript worksheet; Python FastAPI server; restricted mathematical parser and exact SymPy arithmetic. Keep API credentials server-side and load only through Isaac's canonical service loader. Never label authored guidance or fixture judgments as model results. Unsupported mathematics remains not checked. SQLite owns immutable attempt records, voice transcript excerpts and evaluations. Voice transcript snapshots are captured on connection close; do not claim they are complete spoken turns. External model calls follow learner actions: checking typed answers or collecting exact roots with the practice sliders, Ask for help or starting a GPT-Live voice conversation in the learning space, or Assess conversation in the inline evidence panel (including OpenAI explanations of flagged assertions). Tests exercise known correct, incorrect and unsupported inputs. Run `npm run build` and `.venv/bin/python -m pytest` before committing. Local preview binds to 127.0.0.1.

UX: Keep the interface minimal and clear. Use text for learning content and necessary actions; omit decorative slogans, repeated guidance and explanatory filler.
